The user tested the Modrinth JAR. The exact JAR version, world seed and encounter type were not recorded. Focused reproductions and fixes against the working tree are recorded below. The project is in a feature freeze: refactors and bug fixes are in scope; new features below are documented for later.

Encounter difficulty and rewards felt appropriate for the space start. Keep that balance: the encounters should not become a disproportionately rewarding easy dungeon for players arriving from the ground start. The player likes the encounters themselves.

## Features deferred during the freeze

### Reset NullSpace while preserving the Overworld

An operator command would reset NullSpace's generated dimensions and global state while preserving all physical blocks, entities and builds in the Overworld. Deregistering Overworld ships and pads is acceptable. The eventual design must account for offline players, respawns, travel targets, journals, stored ships, dimension data and regeneration, and describe exactly what is preserved. It must offer a reviewable reset plan and backup/restart procedure before deleting data. No world reset is part of the current implementation batch.

### Sleep through FTL

When everyone aboard a travelling ship is asleep, advance to the end of that ship's remaining FTL travel time and wake its passengers. Scope sleep to the ship and account for other ships, optional investigations, arrivals and offline crew. This is a future feature, not a current bug fix.

### Plant growth consumes oxygen

Growing plants would draw oxygen from their room, using the same finite-air accounting as a leak. The room remains physically sealed. Define which growth stages consume oxygen and the rate before implementing this feature; mature plants, growth attempts and accelerated growth need explicit rules. This remains deferred during the feature freeze.
