# Alpha test report

Copy this when reporting a problem:

**What were you trying to do?**

**What happened?** Include the exact message, or a screenshot if the screen is unclear.

**What did you expect?**

**How can we make it happen again?** A few steps are enough.

**Versions:** NullSpace, Minecraft, Fabric Loader, Fabric API and Java.

**Game:** Single player or server; new world or an older save. For a server, say whether other players were aboard, docked, loading or reconnecting.

**Ship/location:** Ship name, planet or region, and the controller or problem block coordinates if available.

**Evidence:** Relevant client/server log lines and a screenshot. The server logs controller actions, refusals and their coordinates. Keep the original save if a ship, inventory or station has gone missing.

For rendering problems, also include the operating system, GPU, driver and renderer setting. Do not post account credentials or server passwords.

Issue submission and server contact links will be added when the public project is created.
