# NullSpace 0.8.1

Fixes missing natural hab population. Exploring Terra or a landable planet now creates hab dungeons using the existing small, medium and large layouts, with loot, lost crew, logs, powered doors, a golden apple tree and a working Station Core.

Existing worlds do not need a reset. Explore uninhabited regions with Generate Structures enabled. Previously inhabited chunks, vessels and pads are protected; depleted and dismantled habs do not regenerate. Natural placement skips flat worlds, space, the Nether and the End. Terrain suitability can leave a region without a hab.

This release also includes the separate feature-freeze cleanup and verification-harness corrections described in [the repository review](../development/feature-freeze-review.md).

Validation and publication details are recorded after the frozen release check and artifact verification complete.
