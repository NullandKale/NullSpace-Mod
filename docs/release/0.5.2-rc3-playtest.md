# 0.5.2 rc3 changes and playtest

This candidate follows the [rc2 checklist](0.5.2-rc2-playtest.md). The in-game version remains `0.5.2`; use the release filename (`nullspace-0.5.2_rc3.jar`) and `/nullspace version` to distinguish the candidate.

Local verification before tagging: all unit cases pass. The tiny-ship and station-journey work passed its focused native and graphical checks earlier (see the [station work record](../development/station-generation-work.md)). The planet fog fix has not been checked in game. Release CI runs the full suite. This candidate has not had the full local integration sweep.

## Changes

- **Tiny ships.** New space starts default to a nine-by-fifteen bridge-and-engineering ship (Rivet Spark, Halcyon Wisp or Bastion Dart). Beacons can deliver them; they are excluded from random population and salvage. Existing ships are never replaced.
- **Existing stations in journeys.** The station encounter reuses the existing signal, dock, board, paid-resume and cleanup path, with a shared station brief (purpose, maker, capacity, condition, seed).
- **Shipyard station preview** for reviewing generated stations.
- **Ship generation.** Water-containing rooms move to the first floor, functional soil and flooring are protected from shared-slab lights, and optional room draws are weighted by role.
- **`/nullspace version`** reports the packaged CI build label and commit.
- **Planet fog.** The seam at the horizon is removed. Haze on terrain used to stop at the planet sphere for rays pointing below level. Rays at or above level kept their haze, so a hard line appeared at eye level on the surface and underground. Haze now follows the real terrain distance in every direction.

Existing ships and stations are not rebuilt by generation changes.

## Playtest

- [ ] Start a new world. Check the default tiny ship: sleep, craft, fuel, launch, jump, dock, board, return and landing.
- [ ] Pick each tiny maker option at start. Check the interior and exterior of each.
- [ ] Find a station encounter. Dock, board, return, resume the journey and reload.
- [ ] On Terra, look at the horizon from the surface and look down. Check there is no line where haze stops. Repeat while mining underground and in foggy or cloudy weather.
- [ ] Run `/nullspace version` and check it reports `v0.5.2_rc3`.

## Still deferred

Manufacturer station layouts and floors, station dungeons, claiming a station, player-built stations and performance measurements remain unbuilt. This candidate does not claim to deliver them.
