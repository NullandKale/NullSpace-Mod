# NullSpace — alpha listing draft

Build a ship, keep it fueled, and explore space in Minecraft.

Start aboard a working ship above a planet, or start a normal Minecraft world and build your first ship yourself. Choose a destination at the Ship Controller and let the ship handle travel and docking. Open the dock door and walk aboard to explore.

Stations and salvage ships appear as you explore. Look through their different rooms for food, fuel and useful parts. Scouts, freighters and explorers come in three manufacturer styles. Supplies are real and finite: returning does not refill a place you already searched.

## In this alpha

- Single-player space starts with a choice of starting ship.
- Dedicated-server space starts that give new players their own ship above a seeded planet.
- Landable planets and moons, including a landing destination on Terra.
- FTL journeys with optional encounters along the route.
- Automatic docking and doors you can walk through, including during a power outage.
- Shared furnace-compatible fuel, electricity, batteries and upgrade slots.
- Ship damage, cabin air, ship recall and explicit review before leaving disconnected pieces behind.

## Install

Use Minecraft **26.3**, **Java 25**, **Fabric Loader 0.19.5** and **Fabric API 0.164.0+26.3**. Install NullSpace and Fabric API on both the client and the server. Use matching NullSpace files on both sides.

The default space renderer needs an OpenGL backend with OpenGL 4.3 support. Compatibility claims should list the devices and operating systems actually verified for this release.

For a space start in single player, open **Create New World → Start**, choose a space start and select your ship. A normal planet start remains available.
